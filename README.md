# AI Career Guidance & Job Matching Assistant

## Project Overview

The AI Career Guidance & Job Matching Assistant is an AI-powered career support system developed using Dify. It helps students with career-related decisions by analyzing their education, skills, CGPA, backlogs, and career goals.

## Key Features

- 🎯 Job Matching
- ✅ Placement Eligibility
- 💼 Interview Preparation
- 📊 Skill Gap Analysis
- 📚 Personalized Learning Plan
- 🧭 General Career Guidance

## Technologies Used

- Dify
- Groq LLM
- Knowledge Base
- Knowledge Retrieval
- Question Classifier
- Parameter Extractor
- Python

## How It Works

The student provides their:

- Name
- Education
- Skills
- CGPA
- Backlogs
- Career Query

The system analyzes the career query and routes it to the appropriate career assistance workflow.

### Job Matching Workflow

Student Input → Career Query Classification → Knowledge Retrieval → Required Skill Extraction → Skill Match Calculation → Job Matching Result

## Knowledge Base

The project uses a career job requirements knowledge base containing required skills for different internship roles, including:

- Frontend Developer Intern
- Backend Developer Intern
- Data Analyst Intern
- AI/ML Intern
- Full Stack Developer Intern
